## 账单与续费

「账单」支持待收款、逾期未付、续费账单、30 天内需续费服务及未设置付款到期日筛选。付款到期日与服务到期日独立；旧账单不会自动补设付款期限，也不会仅因服务到期而算作逾期未付。

未付款账单可调整金额、税额及付款到期日，必须填写原因。详情保留调整前后内容、操作人和时间；编辑版本冲突时需刷新核对。已付款或处理未完成的账单不能调整。确认收款表示运营人员已核实收到全额款项，不调用银行或支付网关。

运营端手动续费会立即延长服务并生成续费账单，多年续费按套餐单价乘以年数计费；之后确认收款不会再次延期。客户门户申请的续费在确认收款后延期。同站点已有未付续费账单时复用该账单，不重复创建；年限不一致时先核对现有账单。暂停的服务不会因续费自动恢复。

如收款或续费写入中断，待处理记录保存在 `console/billing-pending/`，再次处理同一账单可继续完成，不重复计入收入或延期。不要手动删除待处理文件。若提示账单或服务到期日在处理期间发生变化，应先核对账单、账本和站点资料；系统不会覆盖冲突数据。历史已付款账单不会重新入账。账单操作权限以当前角色配置为准。

## 发布前验证与 CI 证据

CI 在源代码测试和依赖审计通过后生成版本固定的发布包，再执行 `preproduction` 门禁：验证发布包的版本与文件摘要，使用同一提交的测试脚本，在解包目录运行浏览器回归。服务使用临时账号及业务数据，通过真实 HTTP 接口交互；外部 WordPress、LLM 或云供应商仍按各测试的明确 fixture 边界处理，不能据此宣称真实外部集成已经验证。

生产部署工作流等待整个 CI（包括预发布门禁）成功，再部署同一提交的发布包。浏览器阶段失败时保存 `browser-failure-<SHA>`；预发布阶段保存 `preproduction-<SHA>`，含结果、日志及生成的截图或追踪文件，保留 7 天。证据只来自隔离测试数据，不应将生产会话、凭据或运行目录加入这些 artifact。

本机验证已有发布包：

```bash
python tools/kf_preproduction.py /path/to/release.tgz \
  --revision <完整提交SHA> --output /tmp/kf-preproduction
```

需先安装锁定的 Python 依赖、`tests/ui` 的 npm 依赖和 Chromium。该命令不部署或修改生产实例；失败时先查看输出目录中的 `result.json` 和 `browser.log`。

## 备份

需备份站点文件、数据库以及完整控制台配置（包含加密密钥）：

```
sites/<slug>/html/        站点文件
sites/<slug>/db/          数据库文件
console/                  账号、账单、客户、账本、配置及加密密钥
```

示例（每日 02:00）：

```bash
tar czf /backup/kf-$(date +%F).tgz \
  -C /opt/kampongflow sites console
```

数据库也可以从容器里 dump：

```bash
docker exec kf-<slug>-db-1 sh -c 'exec mariadb-dump -uroot -p"$MARIADB_ROOT_PASSWORD" wordpress' \
  > backup-<slug>.sql
```

## 排障

**后台打不开**

```bash
systemctl --user status kf-console
journalctl --user -u kf-console -n 50
```

**站点 502**

```bash
docker compose -f sites/<slug>/docker-compose.yml ps
docker compose -f sites/<slug>/docker-compose.yml logs --tail=50
```

**发布后页面没变**

后台该页「对比」看差异；发布失败会自动回滚，`console/updates.json` 里有记录。

**DNS 不生效**

后台 DNS 页先点「本机解析检查」（我们自己解得对不对），再点「公网委托检测」（外面能不能找到我们）。
后者报「公网解析不到」通常是缺 glue 记录，不是代码问题。

**磁盘占用**

```bash
du -sh sites/*/ | sort -h
docker system df
```

镜像清理：`docker image prune -f`（只清无标签的）。

## 系统设置：LLM 与 MCP

导航「系统设置 → 设置 LLM」集中管理服务商、模型、默认配置和连接测试。原配置保持不变，AI 建站仍可选择已保存的模型。LLM 设置与 MCP 管理仅对管理员开放。

「系统设置 → MCP 管理」支持新建、编辑、搜索、启用、停用及删除远程服务。填写唯一 ID、名称、MCP HTTPS 地址和可选 Bearer Token，保存后点击「测试连接与能力」。连接测试先初始化会话，再按服务声明读取工具、资源和提示词列表（每类最多 100 条、5 页，结果过大时提示截断）。最多同时测试两个服务，总体时间预算 45 秒；测试结果仅展示在当前页面，不保存服务返回的内容。

当前支持 Streamable HTTP（JSON / SSE 响应），协议版本 2025-06-18 与 2025-03-26。连接只允许公开 HTTPS 标准端口，校验解析地址并固定连接 IP，拒绝重定向。Token 留空保留旧值；更换地址时必须重新填写或清除 Token。OAuth 登录、本地 stdio 和旧版 HTTP+SSE 独立端点暂不支持。启用服务后仍须配置用途、站点范围和能力白名单，才允许运营助手调用。未配置白名单不会授予 AI 自动调用权限。

运行目录 `console/mcp-servers.json` 保存配置与加密 Token，`console/mcp-vault.key` 保存独立加密密钥，文件权限均为 600；必须一起备份且限制备份访问。凭据不回传页面，不写入审计，不进入代码发布包。所有修改使用版本校验避免覆盖其他操作。

协议依据：[MCP 传输规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[连接生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)。


## 运营助手与受控工具

在「站点运营 → 运营助手」选择站点和操作。管理员与有对应业务权限的运营人员可使用；财务无权限。内置工具复用建站、发布、DNS 和邮件业务接口，MCP 用于接入外部资料和能力。所有操作先生成带参数摘要和版本的操作单，写操作必须核对后确认；根域记录、MX、NS 等敏感 DNS 修改还需当前账号的 TOTP。操作单 30 分钟过期；草稿、域名、发送配置、MCP 定义改变后需重新生成。

### 配置 MCP

管理员在「系统设置 → MCP 管理」测试能力后，将需要的工具、资源 URI 或提示词加入白名单，选择用途（建站、DNS、邮件、维护）和允许使用的站点。工具执行模式为只读、草稿、确认或 TOTP；**模式是管理员对远程能力的信任声明，系统不能证明第三方工具确实只读**。远程有写权限的工具不要标为只读。可用参数绑定把工具的域名参数固定为当前站点域名；同时应使用服务端限定到对应站点的 API 凭据。

每个服务有每小时调用上限及超时，每服务最多 2 个并发调用，运营工具全局最多 4 个并发。工具执行前再次比对完整输入 schema 并校验参数，禁止在线解析外部 schema 引用。工具名称、资源 URI、提示词名称均须在白名单内。提示词获取只提供可选择的参考内容，不会自动成为系统指令。连接 Token 加密保存，不能把密码或 API Key 填到工具参数中。

### DNS 与邮件

先运行「检查域名与邮件解析」识别实际权威托管。管理员在运营助手配置本站点 DNS 服务商：Cloudflare 需要 Zone ID 和该区域 DNS 编辑权限的 API Token；本机 DNS 仅在公网确实委托给本机配置的 NS 时可写。其他托管商当前提供诊断，需要外部受限 MCP 或另行接入服务商适配器。配置中的凭据加密，不回传明文。旧 DNS 页面提交修改也会进入相同的预览确认流程；本机区域记录不代表公网实际托管。

DNS 修改展示旧值、新值及托管商，执行前再次检查区域、版本和现有记录。执行成功只表示服务商接受了修改；随后运行「验证已提交的 DNS 变更」，提供原操作 ID，检查服务商记录和权威服务器。递归缓存可能仍按 TTL 延迟更新。MX/SPF/DKIM/DMARC 检查是基础配置检查，不等于完整 SPF 展开、DKIM 签名验证或邮件投递测试；DKIM 需填写服务商提供的选择器。

邮件继续使用系统已有 SMTP / Resend / SendGrid 配置。「生成邮件草稿」不发送；编辑收件人、主题和正文后生成发送操作单，核对发件人并确认。每张操作单最多执行一次发送，重复点击返回已有结果。发送超时可能发生在服务商接受之后，必须先核实，不能盲目重发。

发送结果的 accepted 表示服务商接受，不代表投递。「查询邮件投递状态」使用已完成发送操作 ID：Resend 需邮件读取权限，SendGrid 需 Email Activity API 权限及对应保留期；无权限、无唯一匹配记录或 SMTP 无通用查询接口时返回未知。已投递表示收件服务器接受，不保证阅读或进入收件箱。查询只读取状态，不重新发送。

### 跨功能交付流程

在运营助手填写建站要求，可选择沿用 AI 建站页当前的参考风格、提示词方案、资料选择和模型；必须选中同一个已有站点。可附加最多 5 条 DNS 变更及交付邮件要求。流程依次为：生成草稿 → 等待预览确认发布 → DNS 变更及权威验证（可选）→ HTTPS / 证书检查 → 生成并确认交付邮件（可选）。流程完成中的邮件阶段代表已接受发送，最终投递可另行查询。

流程自动执行只读和草稿步骤，在发布、DNS 写入和邮件发送处等待人工确认。可暂停、恢复，在当前步骤失败后重试；已完成的发布和发送不会重放。可编辑待确认的邮件正文或其他允许修改的当前步骤，旧操作单取消并重新生成。DNS 或 HTTPS 验证未通过时，仅重试验证，不重复变更。

重启后运行中的流程暂停；执行中的操作标记为中断。外部写操作报错可能标记为 uncertain。管理员必须在操作详情中依据服务商/网站实际结果人工登记成功或失败并说明原因，之后恢复流程；登记不再次执行原请求。只读失败可以重新执行；不要用新操作单绕过尚未核实的发送或 DNS 写入。

### 数据、审计与发布

操作记录保存在 `console/actions/`，流程保存在 `console/workflows/`，目录权限 700，记录 600。记录包含业务参数和结果，仅操作发起人或管理员可查看；全局审计不写邮件正文或连接凭据。列表显示最近 200 张操作单，历史文件仍保留；应按业务保留策略归档，不要删除流程仍引用的记录。

备份整个运行目录 `console/`，包括 `dns-providers.json` / `dns-provider.key`、`mcp-servers.json` / `mcp-vault.key`、`automation-auth.json` 和上述动作、流程目录。密钥与加密数据缺一不可，备份也包含敏感业务内容。代码发布包不包含或覆盖这些文件。发布器在有执行中的建站任务、操作或流程时拒绝部署；先等待完成或暂停流程，保留待确认状态，再重新部署。

接口均需当前浏览器会话与业务权限：`GET /api/automation/config`、`/actions`、`/action/<id>`、`/workflows`；`POST /api/automation/available`、`/prepare`、`/execute`、`/cancel`、`/reconcile`、`/dns-provider`、`/dns-records`，以及 `/workflow/create`、`/workflow/control`、`/workflow/amend`。确认执行绑定操作 ID、摘要和版本，不能修改已审批参数。

投递查询依据：[Resend 邮件查询](https://resend.com/docs/api-reference/emails/retrieve-email)、[SendGrid Email Activity API](https://www.twilio.com/docs/sendgrid/api-reference/email-activity/filter-all-messages)。

## 多供应商账号与新加坡供应商

在「系统设置 → 供应商账号」创建账号，选择允许使用的站点和能力；在「运营助手」为站点绑定 DNS、邮件账号。保存配置不会修改 DNS、发送邮件或购买资源。域名注册机构与实际 DNS 托管机构可能不同，应按公网 NS 委托选择 DNS 执行供应商。

| 供应商 | 当前接入范围 |
| --- | --- |
| Cloudflare | DNS、区域清单、官方 MCP Token 认证 |
| AWS | Route 53、EC2 清单、SES 发送、官方 MCP SigV4 认证 |
| Azure / Google Cloud / 阿里云 / 腾讯云 | 公网 DNS、虚拟机清单 |
| Name.com | Core API DNS 查询、新增、修改、删除 |
| CLDY | SMTP 邮件发送；DNS、主机仍在 CLDY / cPanel 后台管理 |
| Resend / SendGrid / Postmark / Brevo / Mailgun | 邮件发送 |
| 通用 SMTP | 支持密码或应用密码的企业邮箱，TLS 465 / STARTTLS 587 |

Name.com：在官方后台启用 API，填写 API 用户名和 Token，DNS 区域填写域名。使用生产 Core API `https://api.name.com/core/v1`，不使用已弃用的 v4。必须使用 Name.com 权威 DNS，TTL 至少 300 秒；MX / SRV 优先级会转换，ANAME 等不支持的记录仅展示、禁止修改。超过 1000 条记录的区域拒绝执行，避免部分清单造成错误覆盖。没有接入域名购买、续费或转移。

CLDY：在账号供应商中选择 CLDY，依据开通邮件或 cPanel 的邮箱客户端配置填写 SMTP 主机、端口、邮箱用户名和密码，再绑定站点。不能把 CLDY 客户门户登录密码当作邮箱密码。管理入口为 https://manage.cldy.com；域名管理页面可保存机构、后台地址和配置信息，其登录密码继续通过现有 TOTP 查看流程保护。目前没有确认并接入 CLDY 公开管理 API / MCP，不能自动创建邮箱、操作主机或变更 CLDY DNS。SMTP 接受邮件不代表最终投递，需结合 Message-ID、退信或后台记录核实。

账号能力代表已实现的适配器范围，不代表所有供应商产品均已支持。复杂 DNS 路由、别名和非默认线路禁止修改；AWS / GCP 的记录集修改保留其他值，Azure 使用 ETag 条件请求。公网委托、站点范围、配置版本和记录快照会在执行前复核。云资源清单是供应商账号权限范围的只读结果，实际资源隔离还需 IAM / RAM / RBAC。AWS `role` 使用服务器 SDK 凭据链；`keys` 使用显式凭据。MCP 仅允许官方 AWS / Cloudflare 端点使用对应账号认证，其他服务仍可使用通用 HTTPS MCP 配置。

站点邮件绑定作用于运营助手与交付流程；现有全局邮件入口仍使用全局配置。Resend / SendGrid 支持已有投递查询，新增 SES / Postmark / Brevo / Mailgun 当前保存发送回执并提示后台核实最终状态，不会把 API 接受请求当作已投递。发送操作不自动重试。

参考官方资料：[Name.com DNS API](https://docs.name.com/api/v1/reference/dns/list-records)、[Name.com 认证](https://docs.name.com/guides/authentication)、[CLDY cPanel 指引](https://www.cldy.com/support/help-category/cpanel/)。

### 新加坡供应商第二批适配（2026-11-05）

| 账号类型 | 当前可用操作 | 账号要求 |
| --- | --- | --- |
| WebNIC | Basic / Subscription DNS 查询、记录新增/修改/删除；同名记录集保留其他值 | 经销商 API 用户名、Secret Key、出口 IP 白名单；DNS 区域需已存在且公网已委托 |
| 通用 cPanel | 托管域名清单；A/AAAA/CNAME/MX/TXT/NS/SRV 记录查询与变更 | 套餐开放 UAPI / API Token / Zone Editor；公网 HTTPS 2083 或 443；有效证书 |
| Vodien / Dreamscape | 经销商域名清单、状态；当前站点与注册域名完全匹配时读取到期日期和锁定状态 | Dreamscape Reseller ID 与 API Key，须已开通经销商 API；不是 Vodien 普通门户密码 |
| ReadySpace Singapore | 域名清单与到期日期、服务清单与下次到期日期 | 新加坡账户的 Bearer Token 或供应商允许的 Basic 认证 |

在「系统设置 → 供应商账号」创建并保存账号，再点击「测试连接」。测试只调用读取接口，不证明 DNS 写权限，也不会自动修改 NS、开通服务、注册或续费。配置保存不会触发测试。停用账号不能测试，修改账号版本后旧测试请求失效。

WebNIC 的 `production` 和 `ote` 使用独立凭据；更换环境须重新填写全部凭据。OTE 可进行只读连接测试，不能绑定为公网 DNS 执行账号。仅支持普通记录；带特殊 attributes 的路由记录集不允许写入。执行前重新读取快照，更新时保留同名记录的其他值；WebNIC 没有在这些接口中提供与 cPanel SOA serial 等价的条件更新参数，因此不能保证与服务商后台同时编辑时完全原子。执行期间应避免并行编辑同一区域。记录集改名或改类型需分别删除、新增。

通用 cPanel 可用于 CLDY、Oryon、HostSG、Vodien 等实际提供 cPanel 且开放对应权限的账号；品牌不等于权限保证。填写真实 cPanel 主机地址，如 `https://panel.example.com:2083`，不填写客户门户 URL 或 `cpsess` 会话路径。使用 API Token，不使用 root/WHM Token。若供应商没有开放 Token 或 DNS 权限，连接测试/执行会报错，应由供应商开通。CLDY SMTP 账号继续独立管理，无需修改旧邮件配置。

cPanel 解析完整区域并读取 SOA serial，提交时携带该版本。即使当前站点只是区域中的空子域名，也会校验整个区域的版本，阻止依据旧行号覆盖其他记录。根 NS/SOA 仍禁止通过运营助手修改；TXT 按 UTF-8 字节分段；无法安全解码的二进制区域拒绝修改。

Vodien 本轮不支持 DNS 写入：其 SOAP 记录模型未提供现有流程所需的 TTL 管理等一致语义。域名购买、续费、转移、删除、主机销毁未开放为自动化操作。公开返回数据只保留域名、状态、到期和锁定信息，不返回 AuthKey（域名转移密码）或联系人资料。`test` 环境为 Dreamscape 沙箱，显示测试账户数据。

ReadySpace 的 Basic 认证是否可用取决于账户安全设置；启用 MFA 后如被拒绝，不应关闭 MFA。可填写供应商完成授权后获得的 Bearer Token，过期后更新。当前不自动执行供应商登录、MFA challenge 或 Token refresh，不自动发送验证码。服务清单中的到期信息可能是下次计费日期，不代表自动续费授权。

参考接口：[WebNIC DNS](https://apidoc.webnic.dev/get-zone-records-12386566e0)、[WebNIC 认证](https://apidoc.webnic.dev/generate-webnic-token-v2-11979541e0)、[cPanel parse_zone](https://api.docs.cpanel.net/openapi/cpanel/operation/dns-parse_zone/)、[cPanel mass_edit_zone](https://api.docs.cpanel.net/openapi/cpanel/operation/dns-mass_edit_zone/)、[Dreamscape SOAP 文档](https://reseller.ds.network/docs/api.php)、[ReadySpace SG API](https://cloud.readyspace.com.sg/userapi/)。

### 安全版本运行时迁移

安全版本要求 Python 3.12+。先在独立虚拟环境执行 `python -m pip install -r requirements.txt -c constraints.txt`，运行测试和依赖审计后再切换服务的 Python 路径及 PATH。旧虚拟环境保留用于回滚，不要原地升级共享环境。通知定时任务及旧分享控制台也必须切换；只升级主控制台不能保护旧链接。发布脚本会拒绝依赖版本不匹配的运行时。CI/CD 的 `DEPLOY_PYTHON` 必须指向新环境。

发布后验证主控制台与旧分享服务的代码摘要、进程 Python 路径、HTTPS 健康状态、预览样式和资产拒绝行为。刷新已有后台标签页以取得 CSRF 令牌。已有会话保持有效；MFA 变更会主动撤销其他会话。

## WordPress 安全基线

新站开通会自动安装 `kf-security.php` MU 插件并应用 Web 访问规则。已有实例可在 Docker 操作权限下运行：

```sh
python3 tools/kf_wp_harden.py --base /path/to/installation --slug site-slug
```

策略覆盖：拒绝 XML-RPC、禁止 uploads 下 PHP/脚本访问、拒绝配置备份和 readme 访问、关闭后台文件编辑及调试显示、将 wp-config.php 设置为 WordPress 用户所有的 0600。不会替换客户主题或删除现有文件。未接入 MVP SSO 的站点关闭密码、旧 Cookie、Application Password、注册和找回密码登录；前台展示及联系表单保留。正式 HTTPS 地址配置后通过现有 `kf_sso_install.py` 接入，再由 MVP 管理后台。WP-CLI 仍仅作为服务器运维入口使用。

联系表单增加字段类型/长度与 16 KiB 请求体限制。限流由数据库命名锁串行执行，单 IP 每 60 秒一次，全站每 60 秒 100 次；IP 仅以加盐哈希保存。锁获取或数据库操作失败返回 503，不写线索、不发送邮件。触发限流返回 429，蜜罐请求不消耗配额。原主题限流仍可作为额外限制。

工具在站点 `.security-backups/<timestamp>/files.json` 保存私有快照（含 wp-config，0600，不得上传仓库），失败会恢复所改文件。需要主动回滚时使用 `--restore <snapshot-directory>`。重复执行不会叠加规则；停止的站点使用无网络临时容器修改文件，不启动该站点服务。核心或主题版本升级与这些策略分离，持续通过官方安全更新维护。

CI 执行 `php tests/wp_security_test.php`，验证未接入站点认证关闭、XML-RPC 方法清空、联系表单校验和限流边界。部署前还应在临时 Apache 实例验证规则及回滚，并在隔离数据表验证并发限流；不得向生产表单发送真实测试邮件。

## E2E 真实接口验收

`npm run test:real --prefix tests/ui` 启动临时数据目录中的真实 Python HTTP 服务，通过浏览器完成密码登录、退出与旧会话失效、运营/财务权限、TOTP 重放拒绝及草稿保存→重载→预览。没有替换接口响应或注入登录 Cookie；临时账号及草稿在结束时删除。此项已加入默认 UI 测试。它不代表生产认证或 WordPress 发布完整闭环。

`npm run test:live-mcp --prefix tests/ui` 额外通过项目真实 MCP 管理界面连接 Cloudflare 文档和 AWS Knowledge，执行真实远程协议握手及能力发现；不操作云资源，不使用生产账号凭据。该项依赖外网服务，不加入每次 CI 的强制门禁。

生产只读检查需显式提供地址：

```sh
E2E_CONSOLE_URL=https://mvp.ai-da.sg \
E2E_WORDPRESS_URLS=https://kevin.ai-da.sg,https://preschool.ai-da.sg,https://tech.ai-da.sg,https://clinic.ai-da.sg \
npm run test:production --prefix tests/ui

KF_SHOWCASE_URLS=https://preschool.ai-da.sg,https://tech.ai-da.sg,https://clinic.ai-da.sg \
npm run test:showcases --prefix tests/ui
```

生产脚本检查真实登录页、未认证 API、WordPress SSO 入口和安全规则，不提交表单或修改账户。展示站脚本检查四种宽度、导航、图片、表单标签、减少动效偏好。真实 LLM 生成、WordPress 发布、DNS 修改及发送邮件需明确专用站点/资源与收件人，不能以 mock 测试通过替代。

Python 解释器可由 `PYTHON` 指定，浏览器模块可由 `PLAYWRIGHT_MODULE` 指定。真实接口测试结果写入 `output/e2e-real/`，失败保存截图和 Playwright trace；这些文件可能含测试会话，已加入 Git 忽略规则。`E2E_FILTER` 可按场景名称筛选，`E2E_OUTPUT` 可指定单次重跑目录。原 `console.test.cjs` 仍是模拟 API 的 UI 回归，报告中应单列，不算真实业务集成。

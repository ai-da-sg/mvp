# 运维

## 日常操作

| 场景 | 做法 |
|---|---|
| 开通站点 | `tools/kf_provision.sh "公司" "域名" slug 端口 [套餐] [价格] [行业]` |
| 暂停/恢复 | 后台「站点」行内按钮 |
| 续费 | 后台「站点」→ 续费，或客户付款后自动延期 |
| 查谁改了什么 | 后台「团队」→ 操作日志，可按人/关键词/日期筛 |
| 看今天要到期什么 | 后台「客户」→ 顶部续费看板 |

## 备份

必须备份的只有三样：

```
sites/<slug>/html/        站点文件
sites/<slug>/db/          数据库文件
console/*.json            账号、账单、客户、账本
```

示例（每日 02:00）：

```bash
tar czf /backup/kf-$(date +%F).tgz \
  -C /opt/kampongflow sites console/*.json
```

数据库也可以从容器里 dump：

```bash
docker exec kf-<slug>-db-1 sh -c 'exec mariadb-dump -uroot -p"$MARIADB_ROOT_PASSWORD" wordpress' \
  > backup-<slug>.sql
```

## 排障

**后台打不开**

```bash
systemctl --user status kf-console
journalctl --user -u kf-console -n 50
```

**站点 502**

```bash
docker compose -f sites/<slug>/docker-compose.yml ps
docker compose -f sites/<slug>/docker-compose.yml logs --tail=50
```

**发布后页面没变**

后台该页「对比」看差异；发布失败会自动回滚，`console/updates.json` 里有记录。

**DNS 不生效**

后台 DNS 页先点「本机解析检查」（我们自己解得对不对），再点「公网委托检测」（外面能不能找到我们）。
后者报「公网解析不到」通常是缺 glue 记录，不是代码问题。

**磁盘占用**

```bash
du -sh sites/*/ | sort -h
docker system df
```

镜像清理：`docker image prune -f`（只清无标签的）。

## 定时任务

| 任务 | 时间 |
|---|---|
| 每日摘要 | 每天 09:00 |
| 镜像更新检查 | 每周一 09:00 |

临时手动发一次摘要：后台「维护」→ 立即发送日报。

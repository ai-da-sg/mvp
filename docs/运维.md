# 运维

## 日常操作

| 场景 | 做法 |
|---|---|
| 开通站点 | `tools/kf_provision.sh "公司" "域名" slug 端口 [套餐] [价格] [行业]` |
| 暂停/恢复 | 后台「站点」行内按钮 |
| 续费 | 后台「站点」→ 续费，或客户付款后自动延期 |
| 查谁改了什么 | 后台「团队」→ 操作日志，可按人/关键词/日期筛 |
| 看今天要到期什么 | 后台「客户」→ 顶部续费看板 |

## 备份

需备份站点文件、数据库以及完整控制台配置（包含加密密钥）：

```
sites/<slug>/html/        站点文件
sites/<slug>/db/          数据库文件
console/                  账号、账单、客户、账本、配置及加密密钥
```

示例（每日 02:00）：

```bash
tar czf /backup/kf-$(date +%F).tgz \
  -C /opt/kampongflow sites console
```

数据库也可以从容器里 dump：

```bash
docker exec kf-<slug>-db-1 sh -c 'exec mariadb-dump -uroot -p"$MARIADB_ROOT_PASSWORD" wordpress' \
  > backup-<slug>.sql
```

## 排障

**后台打不开**

```bash
systemctl --user status kf-console
journalctl --user -u kf-console -n 50
```

**站点 502**

```bash
docker compose -f sites/<slug>/docker-compose.yml ps
docker compose -f sites/<slug>/docker-compose.yml logs --tail=50
```

**发布后页面没变**

后台该页「对比」看差异；发布失败会自动回滚，`console/updates.json` 里有记录。

**DNS 不生效**

后台 DNS 页先点「本机解析检查」（我们自己解得对不对），再点「公网委托检测」（外面能不能找到我们）。
后者报「公网解析不到」通常是缺 glue 记录，不是代码问题。

**磁盘占用**

```bash
du -sh sites/*/ | sort -h
docker system df
```

镜像清理：`docker image prune -f`（只清无标签的）。

## 系统设置：LLM 与 MCP

导航「系统设置 → 设置 LLM」集中管理服务商、模型、默认配置和连接测试。原配置保持不变，AI 建站仍可选择已保存的模型。LLM 设置与 MCP 管理仅对管理员开放。

「系统设置 → MCP 管理」支持新建、编辑、搜索、启用、停用及删除远程服务。填写唯一 ID、名称、MCP HTTPS 地址和可选 Bearer Token，保存后点击「测试连接与能力」。连接测试先初始化会话，再按服务声明读取工具、资源和提示词列表（每类最多 100 条、5 页，结果过大时提示截断）。最多同时测试两个服务，总体时间预算 45 秒；测试结果仅展示在当前页面，不保存服务返回的内容。

当前支持 Streamable HTTP（JSON / SSE 响应），协议版本 2025-06-18 与 2025-03-26。连接只允许公开 HTTPS 标准端口，校验解析地址并固定连接 IP，拒绝重定向。Token 留空保留旧值；更换地址时必须重新填写或清除 Token。OAuth 登录、本地 stdio 和旧版 HTTP+SSE 独立端点暂不支持。启用服务后仍须配置用途、站点范围和能力白名单，才允许运营助手调用。未配置白名单不会授予 AI 自动调用权限。

运行目录 `console/mcp-servers.json` 保存配置与加密 Token，`console/mcp-vault.key` 保存独立加密密钥，文件权限均为 600；必须一起备份且限制备份访问。凭据不回传页面，不写入审计，不进入代码发布包。所有修改使用版本校验避免覆盖其他操作。

协议依据：[MCP 传输规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[连接生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)。


## 运营助手与受控工具

在「站点运营 → 运营助手」选择站点和操作。管理员与有对应业务权限的运营人员可使用；财务无权限。内置工具复用建站、发布、DNS 和邮件业务接口，MCP 用于接入外部资料和能力。所有操作先生成带参数摘要和版本的操作单，写操作必须核对后确认；根域记录、MX、NS 等敏感 DNS 修改还需当前账号的 TOTP。操作单 30 分钟过期；草稿、域名、发送配置、MCP 定义改变后需重新生成。

### 配置 MCP

管理员在「系统设置 → MCP 管理」测试能力后，将需要的工具、资源 URI 或提示词加入白名单，选择用途（建站、DNS、邮件、维护）和允许使用的站点。工具执行模式为只读、草稿、确认或 TOTP；**模式是管理员对远程能力的信任声明，系统不能证明第三方工具确实只读**。远程有写权限的工具不要标为只读。可用参数绑定把工具的域名参数固定为当前站点域名；同时应使用服务端限定到对应站点的 API 凭据。

每个服务有每小时调用上限及超时，每服务最多 2 个并发调用，运营工具全局最多 4 个并发。工具执行前再次比对完整输入 schema 并校验参数，禁止在线解析外部 schema 引用。工具名称、资源 URI、提示词名称均须在白名单内。提示词获取只提供可选择的参考内容，不会自动成为系统指令。连接 Token 加密保存，不能把密码或 API Key 填到工具参数中。

### DNS 与邮件

先运行「检查域名与邮件解析」识别实际权威托管。管理员在运营助手配置本站点 DNS 服务商：Cloudflare 需要 Zone ID 和该区域 DNS 编辑权限的 API Token；本机 DNS 仅在公网确实委托给本机配置的 NS 时可写。其他托管商当前提供诊断，需要外部受限 MCP 或另行接入服务商适配器。配置中的凭据加密，不回传明文。旧 DNS 页面提交修改也会进入相同的预览确认流程；本机区域记录不代表公网实际托管。

DNS 修改展示旧值、新值及托管商，执行前再次检查区域、版本和现有记录。执行成功只表示服务商接受了修改；随后运行「验证已提交的 DNS 变更」，提供原操作 ID，检查服务商记录和权威服务器。递归缓存可能仍按 TTL 延迟更新。MX/SPF/DKIM/DMARC 检查是基础配置检查，不等于完整 SPF 展开、DKIM 签名验证或邮件投递测试；DKIM 需填写服务商提供的选择器。

邮件继续使用系统已有 SMTP / Resend / SendGrid 配置。「生成邮件草稿」不发送；编辑收件人、主题和正文后生成发送操作单，核对发件人并确认。每张操作单最多执行一次发送，重复点击返回已有结果。发送超时可能发生在服务商接受之后，必须先核实，不能盲目重发。

发送结果的 accepted 表示服务商接受，不代表投递。「查询邮件投递状态」使用已完成发送操作 ID：Resend 需邮件读取权限，SendGrid 需 Email Activity API 权限及对应保留期；无权限、无唯一匹配记录或 SMTP 无通用查询接口时返回未知。已投递表示收件服务器接受，不保证阅读或进入收件箱。查询只读取状态，不重新发送。

### 跨功能交付流程

在运营助手填写建站要求，可选择沿用 AI 建站页当前的参考风格、提示词方案、资料选择和模型；必须选中同一个已有站点。可附加最多 5 条 DNS 变更及交付邮件要求。流程依次为：生成草稿 → 等待预览确认发布 → DNS 变更及权威验证（可选）→ HTTPS / 证书检查 → 生成并确认交付邮件（可选）。流程完成中的邮件阶段代表已接受发送，最终投递可另行查询。

流程自动执行只读和草稿步骤，在发布、DNS 写入和邮件发送处等待人工确认。可暂停、恢复，在当前步骤失败后重试；已完成的发布和发送不会重放。可编辑待确认的邮件正文或其他允许修改的当前步骤，旧操作单取消并重新生成。DNS 或 HTTPS 验证未通过时，仅重试验证，不重复变更。

重启后运行中的流程暂停；执行中的操作标记为中断。外部写操作报错可能标记为 uncertain。管理员必须在操作详情中依据服务商/网站实际结果人工登记成功或失败并说明原因，之后恢复流程；登记不再次执行原请求。只读失败可以重新执行；不要用新操作单绕过尚未核实的发送或 DNS 写入。

### 数据、审计与发布

操作记录保存在 `console/actions/`，流程保存在 `console/workflows/`，目录权限 700，记录 600。记录包含业务参数和结果，仅操作发起人或管理员可查看；全局审计不写邮件正文或连接凭据。列表显示最近 200 张操作单，历史文件仍保留；应按业务保留策略归档，不要删除流程仍引用的记录。

备份整个运行目录 `console/`，包括 `dns-providers.json` / `dns-provider.key`、`mcp-servers.json` / `mcp-vault.key`、`automation-auth.json` 和上述动作、流程目录。密钥与加密数据缺一不可，备份也包含敏感业务内容。代码发布包不包含或覆盖这些文件。发布器在有执行中的建站任务、操作或流程时拒绝部署；先等待完成或暂停流程，保留待确认状态，再重新部署。

接口均需当前浏览器会话与业务权限：`GET /api/automation/config`、`/actions`、`/action/<id>`、`/workflows`；`POST /api/automation/available`、`/prepare`、`/execute`、`/cancel`、`/reconcile`、`/dns-provider`、`/dns-records`，以及 `/workflow/create`、`/workflow/control`、`/workflow/amend`。确认执行绑定操作 ID、摘要和版本，不能修改已审批参数。

投递查询依据：[Resend 邮件查询](https://resend.com/docs/api-reference/emails/retrieve-email)、[SendGrid Email Activity API](https://www.twilio.com/docs/sendgrid/api-reference/email-activity/filter-all-messages)。

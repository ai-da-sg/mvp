# 安全

## 账号

- 每个员工一个账号，不共用
- 角色三种：管理员（全权）、运营（内容与站点）、财务（账本与账单）
- 写操作全部进审计，含改动前后值

## 密码

策略：≥10 位、大写/小写/数字/符号至少三类、不含用户名、不在弱密码库。

改密码：团队 → 我的账号 → 修改密码。改完会踢掉该账号其他会话。

## 两步验证

开启：团队 → 我的账号 → 开启两步验证，用验证器 App 扫码或手输密钥，输入 6 位码确认。

开启后**该账号的 Basic 认证立即失效**——这是防止绕过第二因素的设计，脚本调用要改用会话登录。

### 恢复路径（按顺序尝试）

1. 验证器 App 的 6 位码
2. 恢复码（10 个，一次性，开启时显示一次）
3. 管理员在「团队」页点「重置 MFA」
4. 服务器上执行：

```bash
python3 console/kf_console.py --reset-mfa <用户名>
```

第 4 条不需要任何验证，**因此服务器 SSH 权限比后台权限更关键**。

## 登录防护

| 机制 | 规则 |
|---|---|
| 单账号锁定 | 15 分钟内错 5 次，锁 15 分钟 |
| IP 拦截 | 15 分钟内错 20 次，拦 15 分钟 |
| 解除 | 管理员在「团队」页点「解锁」 |

> IP 拦截依赖真实客户端 IP。安装脚本已配置好 HTTPS 反代，
> 反代用 `$remote_addr` 覆盖客户端伪造的 `X-Forwarded-For`，
> 后台还校验反代共享密钥 `console/proxy.secret`。
> 直连后台（不经反代）时，转发头一律无效。
>
> 若自行部署反代，必须同时传 `X-Forwarded-For` 与 `X-KF-Proxy-Secret`。

## 数据

| 文件 | 内容 | 权限 |
|---|---|---|
| `console/users.json` | 账号、PBKDF2 哈希、MFA 密钥、恢复码哈希 | 600 |
| `console/portal_secret` | 会话签名密钥 | 600 |
| `console/settings.json` | 邮件配置（含 API Key 明文） | 600 |
| `console/audit.log` | 操作日志，4MB 轮转 | 600 |

**API Key 目前明文存放**，请确保安装目录不可被其他用户读取（`chmod 700`）。

## 密钥存放

| 文件 | 内容 | 权限 |
|---|---|---|
| `console/secrets.json` | 邮件 API Key、SMTP 口令 | 600 |
| `console/proxy.secret` | 反代与后台的共享密钥 | 600 |

`settings.json` 只存非密钥配置。也可以用环境变量提供：
`KF_SMTP_API_KEY`、`KF_SMTP_PASS`、`KF_SMTP_USER`、`KF_PROXY_SECRET`。

## 已知缺口

- 密钥以明文存储在服务器（已分离文件 + 600 权限，未做磁盘加密）
- 当前用自签证书；拿到域名后应换可信证书
- 无登录验证码/图形码，仅靠锁定
- 审计日志不写入只读介质，root 可改

## 域名管理机构账号

在「域名管理」按网站登记注册商、DNS 服务商、托管商等多个管理账号，保存机构名称、HTTPS 管理后台地址、用户名、密码及配置信息。搜索支持域名、公司、机构、用户名和配置内容。编辑密码留空会保留原密码，勾选清除才会删除。删除账号记录不会删除域名或网站。

默认管理员和运营可管理、查询账号，财务不可访问账号资料。运营自定义权限须包含 `/api/domain/accounts`。列表与编辑接口仅返回是否保存密码，不返回明文或密文；配置信息可直接查询，不应填入密码、API 密钥或恢复码。

点击「TOTP 验证后显示」，输入当前 MVP 登录账号的六位验证器验证码。未启用两步验证时，先在「团队与安全」绑定验证器。恢复码不能用于显示密码。每个验证码仅允许成功显示一次，再次查看须等待下一枚；五分钟内失败五次将暂停验证五分钟，限制跨重启保留。

明文响应禁止缓存，页面显示 30 秒后清空；关闭弹窗、切换页面或浏览器标签页也会清空。已复制到页面外的密码不受自动隐藏控制。查看成功、验证失败和资料变更均记录审计，但不记录密码或验证码。

密码通过 Fernet 认证加密保存。运行目录下的以下文件均为 600 权限，首次保存或验证时生成，不进入代码仓库或发布包：

| 文件 | 用途 |
|---|---|
| `console/domain-accounts.json` | 机构资料及加密密码 |
| `console/domain-vault.key` | 独立加密密钥 |
| `console/domain-vault-auth.json` | 验证失败次数和已消费验证码计数 |

备份必须同时保护账号数据与密钥，并将备份放在受控位置；丢失密钥后无法恢复密码。已有加密记录但密钥缺失时，系统拒绝自动生成替代密钥。服务器管理员拥有文件访问权，因此仍需限制 SSH 和备份访问权限。


## 运营自动化与 MCP

运营工具使用当前会话权限及站点/用途白名单，服务器端持久化操作参数、版本、摘要及审批状态。确认不等于笼统授权后续动作；修改参数必须创建新操作单。敏感 DNS 修改使用当前账号 TOTP，独立持久化重放和失败限速状态。服务重启不会自动重放未确定结果的外部写操作。

MCP 服务可返回恶意内容；参考内容仅作为不可信数据，输出截断和来源追踪不能替代对服务商的信任评估。管理员应准确配置只读模式并使用最小权限、站点受限的远程凭据。工具参数禁止携带常见密码/API Key 字段，连接凭据加密；结果中已知连接 Token 脱敏，但第三方结果仍可能包含业务敏感信息，操作详情按所有者/管理员授权访问。

DNS 写入前核对权威托管和区域范围；本机 DNS 没有公网委托时不可冒充外部托管写入。邮件 API POST 和 SMTP 发送不自动重试。超时、中断或不确定结果需人工核实，核实登记也会审计。生产发布通过共享锁和运行状态检查避免中断正在执行的动作。

## 供应商账号

`console/providers.json` 保存账号元数据及加密凭据，`console/providers.key` 为加密密钥，`console/provider-bindings.json` 保存站点邮件绑定。应与现有 DNS / MCP 数据一同备份并保护密钥文件。公开 API 不回显供应商秘密字段；运营人员不具备管理员账号配置权限。凭据密文绑定账号 ID、供应商和非秘密配置。账号停用、删除、作用域收缩或版本更新使待执行操作重新校验或失效；已绑定账号不可用时不静默改用其他账号。SMTP 更换主机需要重新填写密码，防止将保留的旧密码发往新服务器。

供应商 API 使用固定 HTTPS 端点，禁止跳转，限制响应大小并不自动重试写操作。供应商账号仅可用于明确授权的站点与能力，但不能替代供应商侧最小权限配置。账号管理密码仍通过原域名凭据库的 TOTP 查看机制管理；执行用 API Token / SMTP 密码为只写字段，没有明文查看接口。

### cPanel、WebNIC 与经销商查询

cPanel 使用显式授权主机，限制 HTTPS 443/2083，每次请求重新解析并拒绝内网、回环、保留地址，将连接固定到已验证的公网 IP，TLS 仍验证原始主机名。不跟随重定向；更换主机需重新提交 Token。DNS 变更使用区域 serial 条件更新；响应有大小和读取时间限制，不自动重试写操作。

WebNIC 与 Vodien 使用固定生产/测试端点。WebNIC 访问令牌按凭据指纹隔离，仅在内存限时缓存；Vodien SOAP 只允许 GetDomainList 和 DomainInfo，拒绝 DTD/实体声明及不匹配响应。ReadySpace 只允许新加坡固定主机的域名/服务读取接口。错误信息不包含供应商响应正文或凭据，资源清单通过字段白名单排除门户密码、域名转移密码和联系人资料。

共享凭据库的进程内锁与文件锁支持同线程、同数据目录的嵌套事务，防止 DNS/MCP 在读取供应商凭据时重复获取文件锁而阻塞；其他线程和进程仍需等待事务结束。
